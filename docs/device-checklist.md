# 기기 점검 목록

JVM 테스트·빌드로 확인할 수 없고 **실제 기기(마이크·스피커·이어폰)** 가 있어야 확인되는 항목을 모은다.
기능이 들어갈 때마다 항목을 추가하고, 확인하면 체크와 날짜·기기를 적는다.

## 준비

- 실제 기기 1대 이상(가능하면 제조사가 다른 2대). 유선 이어폰 또는 블루투스 이어폰.
- 로그 보기: `adb logcat -s Recorder Metronome RecordViewModel Transcription LibraryViewModel`
- 녹음 파일 꺼내기(디버그 빌드):
  ```
  adb shell run-as com.largeblueberry.aicompose ls files/recordings
  adb exec-out run-as com.largeblueberry.aicompose cat files/recordings/<파일명>.wav > rec.wav
  ```
- 꺼낸 WAV는 PC에서 재생하거나, 골든 케이스로 추가할 수 있다(`tools/basic_pitch_golden`).

## 1. 녹음 (PCM WAV + BPM + 메트로놈)

관련: `RecordRepositoryImpl`, `Metronome`, `AudioOutputs`, `RecordViewModel` · 트러블슈팅 B-1, B-12

### 1-1. 샘플레이트
- [ ] 녹음 후 로그에 `saved <파일명> (mm:ss, 22050Hz)`가 찍힌다.
  - 44100Hz로 찍히면: 그 기기가 22,050Hz를 거부한 것. 정상 동작(채보할 때 다운샘플)이지만 기종을 기록해 둔다.
- [ ] 꺼낸 WAV가 PC에서 정상 재생되고 길이가 화면 표시와 맞다.

### 1-2. 카운트인과 메트로놈
- [ ] 마이크 버튼을 누르면 카운트인 4박이 들리고, 첫 박이 더 높은 소리(강박)다.
- [ ] 화면 문구가 `준비… 4 → 3 → 2 → 1`로 바뀌고, 박 표시 점이 박마다 옮겨 간다.
- [ ] 카운트인 박마다 진동이 온다.
- [ ] 녹음이 시작되면 **진동이 멈춘다**(모터 소리가 마이크로 들어가지 않게).
- [ ] BPM을 60 / 100 / 160으로 바꿔 가며 클릭 간격이 일정하게 들린다(밀리거나 끊기지 않음).
- [ ] 꺼낸 WAV의 0초 부근에 카운트인 클릭이 **들어 있지 않다**(카운트인 구간은 파일에 쓰지 않는다).

### 1-3. 스피커 / 이어폰
- [ ] **스피커**: 카운트인 뒤 녹음 중에는 클릭이 멈추고, 안내 문구가 "화면의 박자 표시를 따라…"다.
- [ ] **유선 이어폰**: 녹음 중에도 클릭이 계속 들리고, 안내 문구가 "이어폰이 연결됐어요…"다.
- [ ] **블루투스 이어폰**: 위와 같은지. 클릭이 늦게 들리는지(지연) 체감을 메모한다 → 트러블슈팅 B-7.
- [ ] 이어폰 녹음 파일에 클릭 소리가 새어 들어갔는지 들어 본다.

### 1-4. 중단·예외 상황
- [ ] 녹음 중 **홈 버튼** → 돌아오면 "화면을 벗어나서 녹음을 취소했어요", 라이브러리에 파일이 없다.
- [ ] 음악 앱을 재생하다 녹음 시작 → 음악이 멈춘다(오디오 포커스). 녹음이 끝나면 다시 재생 가능.
- [ ] 녹음 중 **전화가 오거나** 다른 앱이 소리를 가져감 → "다른 앱이 소리를 사용해서 녹음을 멈췄어요".
- [ ] **카운트인 중에** 멈춤 → "녹음된 소리가 없어요…", 파일이 남지 않는다.
- [ ] 2분 동안 녹음 → 자동으로 멈추고 "녹음은 최대 2분이라…" + 저장 스낵바.
- [ ] 녹음 중에는 BPM +/− 버튼이 비활성화된다.
- [ ] 마이크 권한을 거부하면 "녹음 권한이 필요합니다."가 뜨고 녹음이 시작되지 않는다.
- [ ] 앱을 다시 열면 마지막으로 고른 BPM이 유지된다.

### 1-5. 라이브러리
- [ ] 저장된 녹음이 목록에 보이고 WAV가 재생된다.
- [ ] 이름 바꾸기·삭제가 동작한다(파일도 함께 바뀌거나 지워진다).

### 1-6. 입력 품질 (채보 품질에 영향)
- [ ] 같은 허밍을 조용한 방 / 소음 있는 곳에서 녹음해 비교한다.
- [ ] 기기에 따라 `VOICE_RECOGNITION` 입력에서도 자동 이득·잡음 억제가 걸리는지(소리가 펌핑되거나 뭉개짐) 들어 본다 → 트러블슈팅 B-1.

## 2. 채보 (백그라운드 작업 · 트러블슈팅 B-18)

로그 필터: `TranscriptionWorker|Transcription|WM-` (작업 id·녹음 id·시도 횟수·단계가 찍힌다)

### 2-1. 기본 흐름
- [ ] 라이브러리에서 악보 만들기 → 항목 아래 "악보 만드는 중… n%"가 오르고, 끝나면 버튼이 "악보 보기"로 바뀐다.
- [ ] "악보 보기" → 악보 화면이 열리고 녹음과 같은 BPM으로 재생된다.
- [ ] 끝나는 순간 문구가 잠깐 "악보 만들기"(처음 상태)로 깜빡이지 않는다(저장 중 → 악보 보기).
- [ ] 악보 목록(악보 기록)에도 새 악보가 보인다.

### 2-2. 화면을 떠나도 계속
- [ ] 채보 중 뒤로 가기 → 메인 → 다시 라이브러리: 진행률이 이어서 보인다.
- [ ] 채보 중 홈 버튼 → 30초 뒤 돌아오면 악보가 완성돼 있다.
- [ ] 채보 중 화면 회전 → 진행 상태가 유지된다.
- [ ] 채보 중 최근 앱에서 앱을 밀어 종료 → 다시 열면 이어서 돌거나(재실행) 완성돼 있고, **악보가 두 개 생기지 않는다**(같은 작업 id → 같은 악보 id).

### 2-3. 여러 개와 경쟁 상황
- [ ] 녹음 두세 개를 연달아 맡기면 하나는 진행, 나머지는 "대기 중"이고 차례로 끝난다.
- [ ] 같은 녹음의 버튼을 빠르게 여러 번 눌러도 작업은 하나다(악보 하나).
- [ ] 대기 중인 녹음을 지우면 작업이 사라지고 다른 녹음의 채보는 계속된다.
- [ ] 진행 중인 녹음을 지우면 앱이 죽지 않고, 그 악보가 남지 않는다(로그에 RECORD_GONE).
- [ ] 완성된 악보를 악보 기록에서 지우면 라이브러리 항목이 다시 "악보 만들기"가 된다.

### 2-4. 실패
- [ ] 소리 없이(무음) 녹음한 파일 → "멜로디를 찾지 못했어요…"가 항목에 남고, 다시 누르면 다시 돈다.
- [ ] 앱을 다시 열어도 실패 문구가 남아 있다(WorkManager 기록). 다시 시도해 성공하면 사라진다.

### 2-5. 채보 품질 (실제 허밍으로)
- [ ] 단성화 기준값(`rearticulationDipRatio`, B-6): 같은 음을 이어 부를 때 음이 잘게 쪼개지지 않는다.
- [ ] 블루투스 이어폰 지연과 위상 탐색 범위(B-7): 첫 박이 한 칸 밀리지 않는다.
- [ ] 1분 녹음의 채보 시간(로그 start → done)을 기기별로 적는다.

## 3. 악보 화면 (렌더링·재생·공유)

관련: `ScoreWebView`, `osmd/index.html`, `MidiPlayer`, `ScoreSharing` · 트러블슈팅 B-15, C-7
악보가 있어야 확인할 수 있다(3단계 채보 연결 이후, 또는 기기 테스트 `ScoreWebViewRenderTest`).

### 3-1. 렌더링
- [ ] 악보 목록에서 항목을 누르면 상세 화면에 오선·음표가 그려진다(흰 바탕).
- [ ] 다크 테마에서도 악보 카드는 흰 바탕, 나머지 화면은 다크.
- [ ] 긴 악보(1분 이상)가 잘리지 않고 끝까지 보이고, 바깥 화면으로 스크롤된다.
- [ ] 화면 회전 후에도 다시 그려진다.
- [ ] 비행기 모드에서도 그려진다(네트워크를 쓰지 않음).
- [ ] 악보 화면을 10번 정도 열고 닫은 뒤에도 느려지지 않는다(WebView 정리 확인). 가능하면 Android Studio Profiler 메모리.

### 3-2. MIDI 재생
- [ ] 재생 버튼 → 소리가 나고 버튼이 "정지"로 바뀐다. 끝나면 다시 "재생"으로.
- [ ] 재생 중 홈 버튼 → 소리가 멈춘다. 돌아오면 "재생" 상태.
- [ ] 재생 중 뒤로 가기 → 소리가 멈춘다.
- [ ] 들리는 템포가 녹음 때 고른 BPM과 맞다.

### 3-3. 공유
- [ ] "MIDI" → 공유 시트가 뜨고, 메신저·드라이브로 보낸 파일이 PC의 DAW/MuseScore에서 열린다.
- [ ] "MusicXML" → 받은 파일이 MuseScore 등에서 열리고 조표·박자·음표가 앱 화면과 같다.
- [ ] TalkBack을 켜면 공유 버튼이 "MIDI 공유", "MusicXML 공유"로 읽힌다.

## 4. 설정 · 권한 · 백업 (트러블슈팅 C-11, C-12)

### 4-1. 권한
- [ ] 앱을 지우고 새로 설치 → 온보딩에서 **마이크 권한 하나만** 묻는다(오디오·저장소 권한을 묻지 않는다).
- [ ] 시스템 설정 → 앱 → 권한 화면에 마이크만 보이고, "인터넷" 항목이 없다.
- [ ] 마이크를 거부하고 다시 거부(영구 거부) → 설정으로 안내하는 대화상자가 뜬다.

### 4-2. 백업
- [ ] `adb shell dumpsys package com.largeblueberry.aicompose | grep -i backup`에서 `ALLOW_BACKUP`이 꺼져 있다.
- [ ] (가능하면) `adb shell bmgr backupnow com.largeblueberry.aicompose`가 백업하지 않는다고 응답한다.

### 4-3. About · 약관
- [ ] 설정 → About 맨 아래에 오픈소스 목록이 보이고, 항목을 누르면 라이선스 원문이 펼쳐진다. Basic Pitch는 NOTICE까지 보인다.
- [ ] 펼친 원문이 깨지지 않는다(한글·특수문자·줄바꿈). 다크 테마에서도 읽힌다.
- [ ] TalkBack에서 항목이 "라이선스 보기/접기"로 읽힌다.
- [ ] 이용약관·개인정보 처리방침이 새 내용(로그인 없음, 기기 안에서만 처리, 클라우드 백업 없음)으로 보인다. 영어 설정에서는 영어로.
